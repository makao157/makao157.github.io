01

Concept overview

An AR-powered navigation concept for the Minnesota State Fair grounds, intended to help visitors find vendors, stages, and amenities in real time. The original portfolio includes a mobile visual concept that connects the fair’s identity with event information and a navigation entry point.

02

Visitor goal & design intent

The visitor goal is straightforward: find something to do and understand where to go. The concept brings event information and wayfinding into a mobile experience that visitors can carry through the fairgrounds. AR navigation is the intended direction; the supplied material does not demonstrate a working AR implementation.

03

Mobile visual design

The supplied design uses the fair’s blue and green identity, prominent event imagery, and a clear mobile layout. The visible screen shows the State Fair logo, menu access, event dates, a daily-schedule section, and a map entry point. These elements connect planning with navigation.

04

Intended navigation journey

The intended flow is to explore the fair’s offerings, choose a vendor, stage, or amenity, and follow navigation toward that destination. This describes the concept’s goal; additional destination-selection and AR route screens were not present in the supplied portfolio material.

05

Concept status & next validation

This page documents the available visual concept. The supplied material does not include research participant counts, usability-test results, launch evidence, or outcome metrics.

A next validation step would be to test whether visitors can find a destination and understand how to enter navigation. A working AR prototype would also need to test location accuracy, readable directions outdoors, and a usable fallback map. These are proposed next steps, not completed project results.
